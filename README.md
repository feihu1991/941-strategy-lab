# 📊 941 策略研究台

多策略横向对比回测平台。核心是德国交易员 **Oliver Kell**（2022 年交易锦标赛 **+941.1%** 夺冠）「价格行为循环」策略的机械化近似，并内置经典对照策略，用于观察**同一批股票在不同策略下的表现差异**。

**纯前端** · 零依赖 · 无后端 · 数据来自免费公共行情接口 · GitHub Pages 部署

🔗 在线访问：https://feihu1991.github.io/941-strategy-lab/

## 🧠 策略实现

所有策略共用同一套执行框架（`core/engine.js`），保证对比口径一致：

- 成交：收盘价决策 + 收盘价成交（可加滑点）
- 止损：**盘中触发**（用当日 low/high 判定，跳空按开盘价成交）
- 费用：开仓 0.08% + 平仓 0.15%（近似佣金 + 印花税）
- 期末强制结算，净值曲线与统计指标严格一致
- 指标按需计算并缓存（25 次回测约 48ms）

| 策略 | 逻辑 |
|---|---|
| **941 价格行为循环** | 趋势过滤（close > SMA_slow 且 SMA_fast > SMA_slow）→ 收盘上穿**已确认**结构高点入场 → 初始止损 = 入场价 − N×ATR → 结构低点抬升时追踪止损 → R 倍止盈 |
| **双均线交叉** | 快线上穿慢线买入，下穿卖出（可选 ATR 止损） |
| **唐奇安通道突破** | 突破前 N 日最高买入，跌破前 M 日最低离场（海龟交易法核心） |
| **RSI 超卖反转** | RSI 自超卖区回升买入，进入超买区卖出 |
| **买入持有** | 首日买入持有到期（基准线） |

**无未来函数**：结构点采用 i±k 摆动 + 延迟 k 根确认（`confirmIdx`），通道类策略使用**前一根**的通道值，全部由框架层保证。

## 🔌 数据源（自动降级）

| 优先级 | 数据源 | 覆盖 | 方式 |
|---|---|---|---|
| 1 | 腾讯 ifzq | A股（前复权） | fetch（CORS 开放） |

## 🔍 已知约束

- 收盘价成交假设：策略在收盘时决策、按收盘价成交，未模拟盘中下单与排队
- 盘中止损用当日最低价判定，可能低估极端跳空损失
- 新浪兜底源不复权，除权日会有跳空
- 单标的满仓、不做空、无仓位管理（策略固有特性，非缺陷）
