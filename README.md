# 📈 941 冠军策略研究台

基于德国交易员 **Oliver Kell**（2022 年交易锦标赛 **+941.1%** 夺冠）「价格行为循环」策略的**机械化近似回测**，对比同一策略在不同股票上的表现。

**纯前端** · 无后端 · 数据来自免费公共行情接口 · GitHub Pages 部署

## ✨ 功能

- 默认展示 6 只股票（A股 + 美股）在策略下的表现卡片
- 每张卡片：策略总收益、对比买入持有、最大回撤、胜率、交易次数、净值迷你图
- 点击卡片查看详情：K线与买卖信号、净值对比曲线、关键指标、逐笔交易明细
- 支持添加任意股票（`600519` / `sh600519` / `AAPL` / `105.AAPL`）
- 策略档位切换：标准 / 稳健 / 激进（SMA、ATR 止损、止盈 R 可调）
- 数据周期切换：1 / 2 / 3 年

## 🧠 策略规则（近似实现）

1. 趋势过滤：收盘 > SMA200 且 SMA50 > SMA200
2. 结构识别：i±2 根 K 线高低点确认 swing（延迟 2 根，避免未来函数）
3. 突破入场：收盘价上穿最新 swing 高点买入
4. 止损：入场价 − 2.5×ATR，结构低点抬升时追踪上移
5. 止盈：3R 止盈 / 跌破追踪止损离场
6. 费用：开仓 0.08% + 平仓 0.15%
